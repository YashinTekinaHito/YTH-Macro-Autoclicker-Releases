YTH Macro Autoclicker is a free autoclicker and macro recorder for Windows. Record your mouse clicks, mouse movements and keystrokes one time, then let the app repeat them as often as you like. If a task depends on the screen, the built-in image recognition finds a button or icon and clicks it, even when the window moved. The app runs from one .exe file: no installation, no admin rights, nothing to set up. It is a portable alternative to TinyTask - with all your macros organized in profiles instead of loose files.


	SMALL OVERVIEW OF SOME FEATURES:

	Smart Image Recognition
- Find and click screen elements using small screenshot snippets within a custom search area selected by you
- Adjustable match sensitivity to handle color changes or shadows
- Scroll-and-retry option if the image isn't currently visible
- Configurable timeouts with fallback actions


	Macro Recorder
- Press your selected hotkey (select in settings) to start recording all your actions
- Toggle individual actions on/off or test them instantly with a dedicated test button


	Standalone Autoclicker Mode
- Click 1-1000 times per second at a fixed point, for a set duration or endlessly
- Adjustable hold time, random offset and usage statistics
