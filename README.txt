YTH Macro Autoclicker is a free autoclicker and macro recorder for Windows. Record your mouse clicks, mouse movements and keystrokes once, then let the app repeat them as often as you like. If a task depends on the screen, the built-in image recognition finds a button or icon and clicks it, even when the window has moved. The app runs from one .exe file: no installation, no admin rights, nothing to set up. It is a portable alternative to TinyTask - with all your macros organized in profiles instead of loose files.


FEATURES

SMART IMAGE RECOGNITION
- Find and click screen elements using small screenshot snippets within a custom search area selected by you
- Adjustable match sensitivity to handle color changes or shadows
- Scroll-and-retry option if the image is not currently visible
- Set the search limit by count or duration
- Configurable timeouts with fallback actions
- Custom actions on a match or after a failed detection, including jump targets and a wait after the click


MACRO RECORDER
- Press your selected hotkey (select in settings) to start recording all your actions
- Record mouse clicks, mouse movements and keystrokes in one take
- Review a recording before saving it
- Toggle individual actions on/off or test them instantly with a dedicated test button
- Add a Stop Macro step to end the whole configuration immediately, including inside custom actions
- Assign Shift, Ctrl, Alt and AltGr combinations to a single key, recording and start/stop
- Use the Add Step picker with categories that expand with a short animation and keep only one category open at a time


COLOR DETECTION AND SYSTEM ACTIONS
- Check a pixel color at a screen position and run actions on a match or after a failed detection
- Build custom actions with notes, jump targets, mouse travel time and a wait after the click
- Start programs, close apps, send Discord webhooks, or shut down and restart your PC with a cancelable countdown
- When a webhook includes a screenshot, send only a selected screen region as a PNG


STANDALONE AUTOCLICKER MODE
- Click 1-1000 times per second at a fixed point, for a set duration or endlessly
- Adjustable hold time, random offset and usage statistics


CONFIGURATIONS
Tired of having "a million" scattered and unorganized files on your PC like in TinyTask or other macro recorders/autoclickers?
No worries, everything is stored and shown right in-app.
- All configurations and data are saved directly on your PC (AppData\Roaming\YTH Autoclicker)
- Organize configurations using custom names, profile images, and notes
- Sort and search all configurations
- Keep each profile self-contained with its steps, settings, statistics and images


CUSTOMIZATION AND SAFETY
- Four themes (dark, black, gray, white) and text outline toggles
- Choose window colors and app colors, with the selected color staying in place
- Animated header backgrounds including Silk, Dust, Horizon, Dot matrix, Prism, Rings, Ember, Ribbon, Glass, Star trails and Neon pulse, plus the calm Simple background
- Language support: 29 languages (listed below)
- Everything stays local: no cloud, no account, and no files created next to the .exe


UPDATES AND PORTABILITY
- Automatic updates on startup
- Standalone portable .exe file (no installation or admin rights required)
- Configs are stored in your Windows user folder (AppData\Roaming\YTH Autoclicker)
